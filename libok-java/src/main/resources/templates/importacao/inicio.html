Cadastrar livros por planilha (CSV)

Use o mesmo formato do arquivo exportado pelo LiBok — inclusive planilhas da versão antiga. Separador ; ou ,, arquivos do Excel ou UTF-8. Você confere tudo antes de gravar.

Exemplo de planilha
Nome do livroAutorCategoriaAssuntoQuantidadeCodigos de registro
Dom CasmurroMachado de AssisRomanceLiteratura brasileira2ROM-001, ROM-002
O Pequeno PríncipeAntoine de Saint-ExupéryInfantilFábula1INF-014
Colunas opcionais: ISBN, Ano de publicacao, Descricao. A coluna Quantidade é opcional; se existir, precisa bater com os códigos.

Trazer dados do LiBok antigo
